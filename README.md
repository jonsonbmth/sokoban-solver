# sokoban-solver

Push-optimal Sokoban solver for make.fun's "Build the best Sokoban solver, 21 November 2026" bounty. Rooms are independent, so each room's 3-4 boxes are solved separately with push-based A* (min-cost box-goal assignment heuristic, dead-square + frozen 2x2 pruning) and the move strings concatenated. Deterministic: every budget is a node count, never the clock. Practice set: 1,000,000 (push-optimal on all 5 levels); house baseline plain-astar scores 200,000.
